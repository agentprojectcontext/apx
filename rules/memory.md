# Memory, RAG & cross-channel store

> Deep dive for [`AGENTS.md`](../AGENTS.md). Read before touching embeddings,
> the message store, compaction, or the vector index.

- **Three files are dated note logs, and they share ONE format** (`core/memory/dated-log.js`): the super-agent's notebook (`~/.apx/memory.md`), a project's local memory (`~/.apx/projects/<apxId>/memory.md`) and a routine's memory. One `## YYYY-MM-DD` heading per day, one `- [HH:MM][channel] note` bullet per note, and today's bullet goes at the end of TODAY'S block — not at the end of the file.
- **A project has TWO memories, and the split is a safety boundary.** Curated `<repo>/.apc/memory.md` (`core/apc/project-memory.js`) is committed, so only a person writes it — there is deliberately no append helper there. Local `~/.apx/projects/<apxId>/memory.md` (`core/stores/project-memory.js`) is never committed and is what `remember` with a `project` appends to. APC's own rule: private runtime memory stays out of `.apc/`, which holds "curated project facts safe for the team". Both are served by `api/agents.js` (`/memory`, `/memory/local`), both are shown in the Memories screen, and both are indexed under `project:<id>` — a memory nothing displays is the bug that started this.
- **Embeddings provider is configurable** (`memory.embeddings`, registry at `core/memory/embed-engines/`: ollama/openai/gemini/tf). `embedOne/embedBatch` resolve via `selectEmbedEngine`, fall back to `tf` on error. Switching provider/model changes the embedder space → run `POST /api/embeddings/reindex` after a switch.
- **The cross-channel message store is the spine.** Every surface logs turns to `~/.apx/messages/<channel>/YYYY-MM-DD.jsonl` via `appendGlobalMessage({channel, ...})`. Feeds the RAG indexer, `search_messages`, and the `# Active threads` block — a channel that doesn't log is invisible cross-channel.
- **History is never shaped like a tool call.** A past tool record replays onto the ASSISTANT side (`renderToolResult`), coalesced into the model's own voice, once per tool the agent ever ran — so its shape is a worked example of how to answer. `[tool <name>] {"command":"…"} → <result>`, which is what it rendered for a week in August 2026, is a worked example of WRITING calls instead of making them: gemini-3.7-flash copied it, the loop saw no `tool_calls`, took the transcript for the final answer and sent it — nothing ran, and where the model copied a result too, a stale one was passed off as fresh. The record form is `[tool result: <name>] (k=v) → <result>`: same information, no wire format to imitate, no `{}`, no `name(`. The same goes for anything else that reaches the prompt — the RAG broker de-fangs a recalled tool row, and `sanitizeAssistantForContext` scrubs a reply that leaked before this was fixed so it stops teaching the shape. Guards: `tool-markup-leak`, `memory-compaction`, `bare-tool-calls`.
- **Progressive compaction** (`core/memory/compactor.js`): fire-and-forget once a chat passes `memory.compact_threshold`; summarizes the oldest into a `type:"compact"` record (light `compact_model`), keeps `keep_recent` verbatim.
- **Vector store is dual-backend + lazy** (`store.js`): tries sqlite-vec (`~/.apx/memory.db`), falls back to a pure-JS JSON store on any load failure. Indexer is incremental (cursor at `~/.apx/memory-cursor.json`), reconciles embedder family changes, broker hard-capped at `memory.broker_budget_ms`. Tests: `memory-rag` + `memory-compaction` (offline: force-TF/force-JSON/mock/temp HOME).
