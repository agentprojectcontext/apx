**APX Android** es una app nativa que encapsula la superficie `/mobile` del
daemon. Mantiene la UI móvil React existente como implementación única; Android
maneja mascota flotante, notificaciones del sistema y apertura de la app.

## Vincular una vez

<Steps>
1. Hacé accesible el daemon desde el teléfono, por LAN o puerto inverso ADB.
2. Ejecutá `apx pair web` en la máquina del daemon.
3. Ingresá URL del daemon y código mostrado dentro de APX Android.
4. Otorgá permiso de notificaciones cuando Android lo solicite.
5. Otorgá **Mostrar sobre otras apps** solo si querés mascota flotante.
</Steps>

La app recibe un token cliente propio `kind: android`. No reutiliza el token
guardado por Chrome o la PWA instalada porque Android aísla almacenamiento por
app. Pairing web existente sigue válido; ambos clientes aparecen en
`apx pair list` y pueden revocarse por separado.

## Configuración del auto una sola vez

Android no permite que una app se otorgue acceso a notificaciones ni permiso
No molestar. Instalación nueva necesita dos switches explícitos del sistema para
experiencia completa:

| Capacidad | Acción única | Necesaria para |
| --- | --- | --- |
| Notificaciones APX | Aceptar solicitud Android | Toda notificación APX |
| Avisos durante conducción | Menú APX → **Permitir avisos durante conducción** y activar APX en pantalla del sistema | Cards flotantes mientras Android Auto activa No molestar |
| Detección de viajes | Menú APX → **Activar detección de viajes** y activar acceso a notificaciones APX | Leer estado y destino de navegación Google Maps |
| Ubicación | Elegir **Mientras se usa la app** | Enviar origen del viaje |
| Overlay | Activar **Mostrar sobre otras apps** | Solo mascota flotante; no necesario para cards del auto |

En configuración Android Auto, mantener **Ver notificaciones de mensajes**
activo. Activar **Mostrar la primera línea de los mensajes** para ver texto APX
en card, no solo anuncio de mensaje nuevo.

<Aside type="caution">
  **Fuentes desconocidas** solo hace falta con APK de desarrollo instalada
  manualmente. Para probar build local, activar modo desarrollador Android Auto
  y ese switch. Release distribuida normalmente no necesita opción desarrollador.
</Aside>

## Comportamiento nativo

- Inicio normal abre `<daemon>/mobile` dentro de la app, no Chrome.
- Mascota flota sobre escritorio y otras apps, puede arrastrarse y recuerda posición.
- Se oculta mientras APX está abierta y reaparece cuando APX pasa al fondo.
- Eventos APX entrantes disparan burbuja, sonido incluido y notificación Android.
- Tocar mascota o notificación abre app nativa en `/mobile`.
- Notificación persistente de mascota incluye acción **Ocultar**.
- Puntos suspensivos exclusivos de app, junto a **Preferencias**, abren opciones
  nativas. Chrome y PWA instalada no los muestran.
- Opciones nativas permiten mutear/reactivar sonido sin desactivar mascota.
- **Preferencias → Notificaciones** muestra permiso Android real. Tocarlo abre
  ajustes de notificaciones de APX en sistema.
- Menú nativo permite activar **Detección de viajes APX**. Con acceso a
  notificaciones otorgado, app detecta inicio y fin de navegación Google Maps
  mediante metadatos de notificación. APX queda silencioso hasta que Maps
  publica destino final confirmado; luego muestra barra nativa con icono de auto
  y acceso directo a Maps. Inicio nuevo envía evento autenticado `trip.started`
  a `/api/mobility/events`, con destino y última ubicación disponible como
  origen. Cambiar destino cierra viaje anterior e inicia evaluación nueva. No
  sube ruta, historial ni contenido completo de notificaciones.
- Daemon pide a Roby revisar tareas y compromisos pendientes usando herramientas
  de solo lectura. Eventos de viaje configurados por usuario se procesan al
  instante, fuera de rondas y presupuesto proactivo, y producen un único aviso
  Telegram. Roby no afirma cercanía ni desvíos sin datos suficientes.
- Con origen y destino disponibles, daemon geocodifica mediante Nominatim,
  calcula ruta con Valhalla/OSRM y busca comercios OpenStreetMap dentro de 700 m.
  Envía máximo tres coincidencias y enlaces Google Maps; cero coincidencias
  verificadas producen silencio.
- Aviso Telegram ofrece **Sí, voy ahora**, **No podré**, **Recordarme luego** y
  **No avisar más hoy**. Recordar luego crea delivery pendiente para próxima
  ronda. Cerrar Maps antes del envío cancela aviso pendiente.
- Delivery de movilidad también genera card Android APX y sonido local cuando
  sonido nativo está activo.
- Mensajes directos APX usan formato mensajería Android. Android Auto puede
  mostrarlos como avisos flotantes y leerlos sin abrir Telegram. Menú nativo
  incluye **Probar aviso Android Auto** para pruebas DHU o vehículo. Android
  Auto activa No molestar; concedé **Avisos durante conducción** una vez para
  permitir que APX lo atraviese.

<Aside type="note">
  Notificaciones en vivo no requieren mascota flotante. APX mantiene un
  WebSocket autenticado foreground y reconecta tras cortes. Desactivar mascota
  solo quita overlay.
</Aside>

## Qué ruta conoce APX

APX **no** recibe polilínea exacta de Google Maps. Android envía último punto
GPS disponible como origen y texto de destino confirmado expuesto por
notificación de navegación Maps. Daemon geocodifica destino y arma ruta propia
con Valhalla; usa OSRM como fallback.

Ruta reconstruida alcanza para buscar corredor y lugares cercanos, pero puede
diferir de Google Maps: no incluye tráfico Google, preferencias de desvío ni
decisiones sobre caminos privados. Si falta origen o destino, APX no afirma
conocer ruta y no evalúa proximidad. Conectarse al auto sin elegir destino no
inicia evaluación.

## Compilar e instalar

```bash
cd src/interfaces/android
./gradlew testDebugUnitTest assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
