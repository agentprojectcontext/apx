# @apx/mobile — pendiente (F7)

Expo (iOS + Android). Operador del core y **nodo** (cámara, ubicación, notificaciones, mascota).
Comparte con web sólo `@apx/protocol` (contrato + cliente) y los tokens de `@apx/ui` — no componentes.
Los widgets/apps se muestran con `react-native-webview` usando el mismo host de `@apx/surfaces`.
Ver `plan/01-arquitectura-v2.md`.
