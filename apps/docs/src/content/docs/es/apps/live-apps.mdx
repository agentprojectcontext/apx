## Abierta no significa actualizada

Una app puede conservar su vista mientras visitás otra pantalla de APX. Eso no vuelve vivos sus datos: la página
debe consultar una fuente o calcular valores nuevos explícitamente. Una vista con caché puede mostrar un resultado
viejo y actualizarlo después. Pedí una fecha visible y estados de error o desactualización, no un número sin contexto.

Por ejemplo:

> Hacé una app viva de estado de servicios desde esta API pública. Actualizá una vez por minuto mientras sea visible,
> conservá el último resultado correcto, mostrá cuándo lo consultaste y marcalo desactualizado si falla. No inventes «en línea».

Para APIs privadas, indicá servicio y datos necesarios, no el secreto en el chat. Configurá el secreto del artefacto
aparte. La fuente puede rechazar pedidos, limitar consultas o no tener la API necesaria; APX no evita esos límites.

## Abrí, salí y volvé

Abrí una app guardada desde **Apps**. Sigue ejecutándose al navegar dentro de APX hasta **Cerrar app**, salir de la
aplicación o desalojarla cuando otra necesite su lugar. El panel conserva hasta **seis apps abiertas**. Si está lleno,
puede cerrar una que no se muestra, empezando por la menos reciente. El punto en Apps indica que está abierta, no
que su fuente de datos esté conectada correctamente.

Un widget normalmente se cierra al salir de su vista completa. Para trabajar con él abierto, usá **Fijar en Apps**.
La acción **Abrir en una ventana nueva** mueve una app a su ventana; cerrarla la devuelve al panel. Abrir a pantalla
completa no cambia por sí solo el tipo widget/app guardado.

## Widgets vivos y visibilidad

Una página puede declarar aparte cuánto seguir viva oculta, por ejemplo para un contador. Este grupo tiene **tres**
lugares, independientes de las seis apps abiertas; las páginas ocultas pueden vencer o ser desalojadas. Las apps
deben pausar temporizadores y conexiones innecesarias cuando no se ven. No dependas de una aplicación oculta o
suspendida para ejecutar un trabajo importante a una hora exacta.

Estos límites describen el panel. No asumas que el teléfono, un enlace público o el escritorio cerrado conservan
la misma instancia viva. Los registros durables son distintos del iframe: la [memoria del artefacto](/es/office/artifacts/)
sobrevive al cierre; las variables sin guardar pueden perderse.

## El trabajo programado va en rutinas

Para «revisá cada mañana y avisame si cambió», usá una [rutina](/es/office/routines/), no un temporizador del artefacto.
La rutina se ejecuta en el core y tiene su resultado y política de avisos. Crear una app viva no crea una rutina,
un servidor permanente ni permiso para publicar o enviar mensajes.

## Si parece congelada

1. Revisá fecha del último éxito y error. La caché no prueba que la consulta sea nueva.
2. Mostrá la app y reintentá actualizar; reconectá APX si está sin conexión.
3. Revisá origen de API declarado y secreto necesario. No quites las protecciones de aislamiento.
4. Reabrí una app desalojada. Los registros guardados deberían seguir; comprobalo antes de borrar su memoria.
5. Pedile al agente que arregle el mismo artefacto en vez de crear otra copia sin registros.
