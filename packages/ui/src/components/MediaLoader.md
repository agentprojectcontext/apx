# MediaLoader

A file still loading: an icon of its kind (`image`, `video`, `audio`, `file`) that moves, over a shimmering box that
fills its parent. Give the box the size the file will take so nothing jumps when it arrives. `inline` keeps just the
icon at text size, for a chip or a button. `mediaKindOf(mime, name)` picks the kind from a MIME type or an extension.
No text: the motion says it is on its way.
