# Card

Generic panel with optional `title`, `description` and `aside` slot.

- `variant="soft"` — warm fill, no border: feature panels, onboarding, empty states (the calm v2 look).
- `variant="surface"` — raised white panel (bordered in classic): settings sections, widgets.
- `variant="outline"` — transparent with border, for grouping on colored grounds.

```tsx
<Card variant="soft" title="Works where you work" description="Log in once. It uses your apps like you would." />
```
