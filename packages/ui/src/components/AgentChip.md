# AgentChip

Inline agent mention: tiny blob + colored name. `variant="chip"` (tinted pill, for SystemNote and headers) or `plain` (colored text inside a sentence). `tone` violet for other agents, brand for your secretary.

```tsx
<SystemNote>Updated memory for <AgentChip name="Ledger" blob="amatista" /></SystemNote>
```
