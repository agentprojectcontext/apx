# GoogleMark

Google's "G" in its own four colours, as Google's sign-in guidelines ask: the leading icon of every "Sign in with
Google" button (the APX account, Google integrations). Never recoloured or altered; 16px in a button.

```tsx
<Button variant="secondary" leadingIcon={<GoogleMark />}>Sign in with Google</Button>
```
