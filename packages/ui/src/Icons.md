# Icons

Curated lucide icon set used by the components, as one object: `<Icons.Search size={16} />`.

- Size 14–18 inside controls, 16 in NavItem/Menu, 12 inside Tag.
- Icons inherit `currentColor`; never color them by hand — color the parent.
- Available: AppWindow, Archive, ArchiveRestore, ArrowDown, ArrowLeft, ArrowUp, Bell, Bot, Brain, Calendar, Check, CheckCheck, ChevronDown, ChevronLeft, ChevronRight, Circle, Clock, Code, Copy, Database, Dices, Download, Ellipsis, ExternalLink, File, FileText, Filter, Folder, Globe, Hand, House, Image, Inbox, Info, Languages, Layers, LayoutGrid, Link, List, ListChecks, LoaderCircle, Lock, Mail, MessageCircle, Mic, Monitor, Moon, PanelRight, Paperclip, Pencil, Pin, PinOff, Play, Plus, RefreshCw, RotateCcw, Search, Send, Settings, Share, Smartphone, Sparkles, Square, SquarePen, Star, Sun, Terminal, Trash2, TriangleAlert, User, Users, WifiOff, Wrench, X, Zap.

```tsx
<IconButton label="New chat" icon={<Icons.SquarePen />} />
```
